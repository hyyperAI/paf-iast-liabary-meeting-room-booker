Guest Data Structure:
```typescript
{
  registrationNo: string,  // Pattern: ^[0-9]{4}-[A-Z]{2,3}-[0-9]{3,4}$
  name: string,            // Min 2 words, letters/spaces only
  phoneNumber: string,     // Pattern: ^\\+92[0-9]{10}$
  email: string,          // Email format
  semester: string        // 1st-8th or 1-8
}
```

```typescript
{
  roomId: string,

  applicantSemester: string (from guestData),
  groupMemberCount: number,

}
```

