Backend Architecture Summary

  Tech Stack

  - Runtime: Node.js with Express.js
  - Language: TypeScript
  - Database: SQLite with Prisma ORM
  - Auth: JWT (jsonwebtoken) + bcryptjs
  - Validation: Zod

  Database Models

  | Model   | Purpose                                                     |
  |---------|-------------------------------------------------------------|
  | Room    | Library rooms with date, timeSlot, status, queue management |
  | Student | Users with registrationNo, role (STUDENT/ADMIN)             |
  | Booking | Room reservations with approval workflow                    |
  | Member  | Group members for bookings                                  |

  API Endpoints

  | Route            | Methods                                         | Description        |
  |------------------|-------------------------------------------------|--------------------|
  | /api/v1/auth     | POST /login, /register, /admin/login            | Authentication     |
  | /api/v1/rooms    | GET /, /:id, /:id/availability                  | Room management    |
  | /api/v1/bookings | GET, POST, PUT, DELETE                          | Booking CRUD       |
  | /api/v1/admin    | PUT /bookings/:id/approve, /bookings/:id/reject | Admin actions      |
  | /api/v1/students | GET /, /:id, /:id/members                       | Student management |
  | /api/v1/queue    | GET /:roomId/:date/:timeSlot                    | Queue status       |

  Key Business Rules

  - Booking restrictions: No past dates, no weekends, only next 3 working days
  - Queue system: Max 5 in queue, position-based ordering
  - Registration format: XXXX-XX-XXX (e.g., 2024-CS-001)
  - Phone format: +92XXXXXXXXXX
